## Project Overview

### Tech Stack

| Category | Technology |
| ------ | ------ |
| Framework | [Plasmo](https://www.plasmo.com/) |
| UI | React + Tailwind CSS v4 |
| Language | TypeScript |
| State Management | Zustand + Immer |
| Persistence | @plasmohq/storage |
| Messaging / Concurrency | @plasmohq/messaging + async-mutex |

### Local Setup

```bash title="Bash"
git clone https://github.com/Ying-Luan/CloudLeaf.git
cd CloudLeaf
npm install

# Start dev server
npm run dev          # Chrome
npm run dev:edge     # Microsoft Edge
npm run dev:firefox  # Firefox

# Build for production
npm run build          # Chrome
npm run build:edge     # Microsoft Edge
npm run build:firefox  # Firefox

# Package for store
npm run package          # Chrome
npm run package:edge     # Microsoft Edge
npm run package:firefox  # Firefox
```

### Architecture

```text
Popup / Side Panel / Settings (UI)
  └── hooks/                   State & side-effect encapsulation
      └── background/          Messages, bookmark events & scheduler
          └── core/sync/       Sync reconciliation (cloud / local)
              └── providers/   Storage backends (Gist / WebDAV / Local)
                  └── BaseProvider → HttpProvider → Concrete implementations
```

### Automatic Sync Flow

The background service worker listens for bookmark changes and schedules a debounced sync about 5 seconds after changes settle. A browser alarm performs another check every 15 minutes, while the settings page can request an immediate `Trigger Sync` message.

The coordinator serializes sync cycles with a mutex, compares normalized bookmark hashes and timestamps, then uploads local data or applies cloud data as appropriate. Applying cloud data is guarded so the resulting bookmark events do not start a feedback loop.

Automatic sync starts in the `uninitialized` phase. A successful manual `Upload Bookmarks` or `Download Bookmarks` records the current sync result and changes the phase to `ready`; conflicts change it to `conflict` and require manual resolution before automatic sync resumes.

## Contributing

We welcome all forms of contribution! Whether to the [code repo](https://github.com/Ying-Luan/CloudLeaf) or [docs repo](https://github.com/Ying-Luan/CloudLeaf-docs) — filing issues, submitting pull requests, or joining discussions — every contribution is appreciated.

### Filing Issues

Submit at [GitHub Issues](https://github.com/Ying-Luan/CloudLeaf/issues) with the following information:

- Browser and version
- Steps to reproduce
- Expected vs. actual behavior

### Pull Requests

1. Fork the repository
2. Create a new branch
3. Ensure `npm run lint` passes
4. Submit a PR with a description of your changes

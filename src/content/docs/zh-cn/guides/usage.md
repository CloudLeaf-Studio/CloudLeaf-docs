## 操作

打开 CloudLeaf 弹窗后，你会看到 [`上传书签`](#上传书签)、[`下载书签`](#下载书签)、[`导出书签`](#导出书签)、[`导入书签`](#导入书签) 四个主要操作按钮。

![popup](../../../../assets/zh-cn/popup.png)

### 上传书签

将当前浏览器中的书签同步到云端。

1. 点击`上传书签`
2. CloudLeaf 会读取当前书签并与云端对比
3. 若无冲突，自动完成上传
4. 若**云端数据比本地新**，会弹出确认框，询问是否强制覆盖

:::caution
上传书签会**覆盖**云端的书签内容。
:::

### 下载书签

从云端恢复书签到当前浏览器。

1. 点击`下载书签`
2. CloudLeaf 会从你配置的同步源拉取书签数据
3. 若**本地数据比云端新**，会弹出确认框，询问是否强制覆盖
4. 下载成功后，当前浏览器的书签会被替换为云端内容

:::caution
下载书签会**替换**当前浏览器的全部书签。可以先在[预览模式](#预览模式)确认内容。
:::

### 导出书签

将当前书签保存为本地 JSON 文件（仅 Chrome 和 Edge 可用）。

1. 点击`导出书签`
2. 文件以 `CloudLeaf.json` 命名保存在浏览器默认下载位置

### 导入书签

从本地 JSON 文件恢复书签（仅 Chrome 和 Edge 可用）。

1. 点击`导入书签`
2. 选择之前导出的 JSON 文件
3. 若本地数据比文件中新，会弹出确认框

## 自动同步

自动同步必须在成功完成一次手动上传后才能初始化。请先配置同步源并完成这次上传，再启用自动同步。

1. 打开弹窗，先点击一次`上传书签`
2. 打开设置页，启用`自动同步`
3. 书签变更停止后约 5 秒，CloudLeaf 会安排一次同步
4. 后台定时任务还会每 15 分钟检查一次变更

你可以在设置页点击`手动同步`立即发起检查。状态指示会显示`未初始化`、`就绪`或`冲突`。如果更换云端目标或最高优先级同步源，请再次手动上传，让新目标记录最新的同步结果。

:::caution
首次手动`上传书签`成功前，自动同步不会开始。检测到冲突后，自动同步会暂停，需要通过手动上传或下载解决。
:::

## 预览模式

随时可以查看云端存储的书签内容，无需执行上传或下载操作。

1. 点击右上角的眼睛图标
2. 侧边栏会展开，显示云端书签的文件夹树
3. 可以浏览文件夹结构，查看云端存储了哪些书签

![sidepanel](../../../../assets/zh-cn/sidepanel.png)

:::tip
预览模式不仅可以用于同步前确认内容，你也可以随时打开侧边栏，直接使用云端书签。
:::

## 冲突检测

CloudLeaf 会先比较规范化后的书签内容，再在内容不一致时比较**本地书签时间戳**和**云端文件时间戳**：

- **已同步**：两端规范化后的内容哈希一致
- **本地较新**：下载时如果本地较新 → 提示是否强制下载
- **云端较新**：上传时如果云端较新 → 提示是否强制覆盖
- **冲突**：内容不同但时间戳相同，需要手动解决后自动同步才能继续
